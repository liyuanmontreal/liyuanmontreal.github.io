昨天我在蒙特利尔科学馆参观了一个因纽特文化展览。我很喜欢因纽特文字，因为文字的几何形状有独特的美观。在一次在书展上，我曾买了一本因纽特文字的书。虽然我一个字也看不懂，但是看这些符号连接在一起，让人有种奇妙又愉悦的感觉，忍不住想了解更多。

于是，昨天我想，干脆现在学一点吧。我查了一些资料，想学习基本会话。我学习了你好。这个单词是在因纽特文中非常简洁漂亮，ᐊᐃ’，我想我永远都不会忘记。但是，其他的单词，看起来就长多了。我发现它们的长度比中文句子要长得多。我用bing翻译玩了一会儿。开始设想是否可以自己构建一个因纽特文到中文的翻译器。虽然这个功能必应翻译已经有了。但是我想了解如果自己做，会遇到什么挑战。简单调研之后，我发现由于因纽特语是一种非常低资源的语言，直接做与中文的翻译难度太大。于是，调整目标为先开发一款因纽特语与英文之间的翻译器。这方面有一些研究资料可以参考，比中文要方便很多。

在调研中，我发现由于因纽特语在语法上与英文有很多差异，因此给构建翻译器带来了很多挑战。在此记录一下：

# 挑战 1：一个词往往相当于一句话（多聚语 Polysynthesis）

因纽特语是典型的多聚语语言（polysynthetic language）。  
一个词可以由词根加上多个后缀组合而成，形成一个类似“句子压缩包”的长词。  
维基百科指出，一个因纽特语词可能包含七个以上后缀，并且由于组合多样性，超过 90% 的词在语料中仅出现一次。

### 示例
qangatasuukkuvimmuuriaqalaaqtunga
├─ qangatasuukkuvik (机场 airport)
├─ -mmu (向 to/toward)
├─ -uriaq (必须 must)
├─ -qalaa (快要 about to)
└─ -qtunga (我 I)

英文：I will probably have to go to the airport.


因为英语单词通常是较稳定的语义单位，而因纽特语的“单词”实际上是动态形态组合，传统 BPE 分词会把长词切碎，破坏其结构，使模型无法恢复原来的语义与语法关系。这为翻译中的对齐与解释带来了巨大难度。

---

# 挑战 2：三种数（单数 / 双数 / 复数）是必需的语法属性

英语只有单数和复数，而因纽特语的名词和动词必须区分：

- 单数（一个）
- 双数（两个）
- 复数（三个以上）

例如：

ikajuuk = “他们俩互相帮助”


英语永远不会明确指出 “they” 是两个人还是更多人，但因纽特语必须在动词上形态化表达人数。翻译器在英语→因纽特语方向必须根据语境推断人数，否则动词的形态变化就会出错，使句子显得不自然甚至不符合语法。

---

# 挑战 3：格系统复杂且精细，远超英语介词的表达能力

英语通过介词（in, from, with, like 等）表达空间与逻辑关系，但这些介词往往有多义性。  
因纽特语使用的是严格且精确的 **格尾（case suffixes）** 系统。维基百科列出了 locative（处所格）、allative（方向格）、ablative（来源格）、instrumental（工具格）、prolative（经由格）等多种格尾。

### 插图示例

英语：in / from / toward / with / like
因纽特语：-mi / -min / -mut / -ngani / -llu ...


例如英语中的 “with” 可能表示陪伴、使用工具、方式或伴随，而因纽特语为这些语义使用不同格尾。翻译器必须准确识别英语介词在语境中的具体含义，再选择正确的因纽特语格尾，这比中英翻译要困难得多。

---

# 挑战 4：施事格系统（ergativity）与动词类别使“谁做什么”变得更复杂

因纽特语使用 **分裂施事格系统（split-ergative）**。  
它不仅根据句子结构，还根据动词是否“带明确对象（specific verbs）”或“不带明确对象（non-specific verbs）”决定主语是否使用施事格。

### 例子

ju umiarlirpuq
= “他在建造一艘（特定的）船”

这里船是明确对象，因此使用特定动词，主语带施事格结构。

ju umiarlirniqtuq
= “他在进行造船这件事（但不是特定某艘船）”

当动作只是一般性活动时，使用非特定动词，主语不带施事格。

由于英语使用固定的 SVO（主语–动词–宾语）结构，而因纽特语依靠格尾与动词类别确定角色，机器翻译必须超越词序，理解动作是否具备明确对象，并据此选择正确动词类型与格标记。这让语义理解变得更加重要。

---

# 挑战 5：动词包含英语缺失的“态度、证据来源、事件状态”等信息

因纽特语的动词后缀不仅表达时间与事件进展（体 aspect），还表达说话者的态度（语气 mood）与信息来源（证据性 evidentiality）。  
英语很少将这些信息整合进动词中，而在因纽特语中它们必须通过形态明确呈现。

例如：

takujunnaqtunga

不仅意味着“我看不到它”，还表示：

- 我尝试过  
- 没成功  
- 现在仍然看不到  
- 并带有无奈语气  

英语不会把这些信息放进动词本身，因此在英语→因纽特语翻译中，模型必须补充这些缺失信息，选择恰当的后缀链构造完整的动词形式。

---

# 挑战 6：从句关系通过动词后缀表达，而不是连词

英语用 because / when / if / although 等连词表达从句；  
因纽特语则把从句关系直接写进动词后缀中，这被称为从句的“词法化”（morphologization）。

### 示例

pisuk-sima-mmam-nga
= “因为他走了，我推测如此”

“-mmam” 表达“因为”，其他后缀表达完成态与推测态度。  
英语的从句结构与因纽特语的这种后缀化结构没有直接对齐方式，使 MT 系统必须先识别英语从句，再将其转换为正确的后缀序列。

---

# 总结

总的来说，英语与因纽特语之间的结构差异几乎存在于语言的每一个层面。因纽特语单词往往由多层后缀构成，语义密度远高于英语。其语法体系包含英语所没有的双数、丰富的格系统以及复杂的动词类别与施事格结构。动词形态还包含态度与证据性等英语通常不显性的语义，而从句功能也被融入动词后缀之中。英语因缺少这些形态表达方式，导致英语→因纽特语方向需要进行语义补全和结构重建，使得生成正确的后缀链成为机器翻译的核心困难之一。因此，English–Inuktitut MT 远比常见语言对更具挑战性，需要形态分析、语义推断与结构化生成等方法共同参与，才能获得自然、准确的结果。

综

因此，英语到因纽特语的机器翻译系统不仅要翻译单词，还要重建缺失的语义区别，生成正确的词法链，并协调截然不同的语法结构。这使得英语-因纽特语机器翻译远比普通语言对更具挑战性。
